# Support

If you need help with Gideon Core, please use the following resources:

## 1. Documentation
Always check the `/docs` directory first. The [Architecture Overview](docs/architecture_overview.md) and [Deployment Guide](docs/deployment_guide.md) solve the majority of setup issues.

## 2. GitHub Issues
If you have found a bug, please open an Issue. Provide as much detail as possible, including logs and configuration.

## 3. Discussions
For questions, architectural discussions, or roadmap ideas, use GitHub Discussions.

## Security Disclosures
If you find a security vulnerability (e.g., an exploit bypassing the `Guardian` service), do **NOT** open a public issue. Please email the maintainers directly.
