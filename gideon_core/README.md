# Gideon: Personal AI Platform

Gideon is a personal AI operating layer designed to sit on top of Windows (initially) and Android. It provides a modular, extensible, and multi-agent architecture for seamless interaction with your devices.

## Architecture Highlights
- **Conversational Core:** Handles wake-words, STT, LLM reasoning, and TTS.
- **Long-term Memory:** Semantic retrieval of projects, preferences, and conversations.
- **Modular Tools:** Capabilities exist as independent tools or plugins (e.g., browser automation, email, coding).
- **Planning Engine:** Translates high-level requests into executable plans.
- **Multi-Agent System:** Specialized agents for planning, memory, research, coding, vision, and voice.
- **Cross-Platform:** Python backend with a Flutter-based shared UI for Desktop and Mobile.
- **Dynamic AI Providers:** Supports NVIDIA APIs, OpenAI, Anthropic, and local models.
